# Gema Digital — Proyecto Web & Identidad

Base de ingeniería para el sitio marketing (**Gema Digital**) y la narrativa de producto (**ERP Cumbre**), implementado en **WordPress local** (Studio) con despliegue a producción en `gema-digital.com`.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `brand/` | Identidad visual: guidelines, tokens CSS, logotipos SVG |
| `wordpress/` | Tema hijo, documentación de entorno local/producción |
| `config/` | Presets Tailwind y variables compartidas |
| `docs/` | Hoja de ruta, arquitectura, referencias al silo de contenido |
| `scripts/` | Utilidades de sincronización y build |
