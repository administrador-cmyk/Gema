# Prompts de Landing para Módulos Cumbre

Esta carpeta reúne los paquetes preparados por la cadena de desarrollo de módulos Cumbre.

Cada archivo debe corresponder a un módulo pendiente y quedar listo para que otro agente implemente la landing web en WordPress.

## Formato recomendado

- Nombre del módulo.
- Objetivo de la landing.
- Público ideal.
- Problema que resuelve.
- Propuesta de valor.
- Funcionalidades principales.
- Módulos Cumbre conectados.
- Casos de uso.
- Guardrails técnicos, legales, comerciales, fiscales o de seguridad.
- Estructura sugerida de landing.
- SEO: title, meta description, keywords, H1/H2/H3 sugeridos.
- CTAs.
- Planes o niveles comerciales.
- Estilo visual.
- Auditoría previa al cierre.
- Próximos pasos.

## Reglas

- No publicar ni desplegar.
- No modificar producción.
- No inventar módulos si ya no quedan pendientes.
- Si no hay módulos pendientes, registrar el cierre en `ESTADO_CADENA.md`.
