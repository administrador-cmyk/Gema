# Repositorio de imagenes del sitio GEMA Digital

Carpeta central del proyecto:

`/Users/norbertosarlinga/Library/CloudStorage/GoogleDrive-info@gema-digital.com/Mi unidad/GEMA/00-Proyecto Gema/03-Imagenes Sitio`

Esta carpeta local queda como espejo tecnico dentro del proyecto web. La fuente ordenada para guardar material final debe ser `00-Proyecto Gema`.

Estructura:

- `originales-flow/`: imagenes originales generadas o descargadas desde Flow u otra herramienta.
- `optimizadas-webp/`: versiones finales comprimidas en WebP para usar en el sitio.
- `prompts/`: prompts usados para generar imagenes.
- `referencias/`: imagenes de referencia, capturas o material visual para direccion creativa.

Criterios:

- Usar nombres descriptivos orientados a SEO.
- Evitar logos externos, datos sensibles y textos legibles en pantallas.
- Optimizar a WebP antes de publicar.
- Mantener una estetica profesional, cercana y alineada a GEMA Digital.
