# Decisión 001 — Dirección de identidad v2

Fecha: 2026-06-04

## Decisión

El logo actual de Gema se conserva como fuente conceptual, pero no como versión final de lanzamiento.

La nueva dirección aprobada es:

- **Gema Digital:** monograma `G` sobrio, vectorial, con señales de red/IA y gema tecnológica.
- **ERP Cumbre:** marca separada con escudo, montaña y barras financieras, orientada a confianza B2B y misión crítica.

## Motivo

El logo actual tiene una idea fuerte: red neuronal, automatización y sistema conectado formando una `G`. Esa idea es útil para Gema Digital.

El problema está en la ejecución:

- Demasiado detalle para favicon y tamaños chicos.
- Estilo 3D/multicolor más cercano a exploración generativa que a marca B2B premium.
- Paleta amplia que compite con la percepción de seguridad y autoridad.
- Slogan `Gestión · Marketing · Automatización` demasiado genérico para la tesis de IA productiva.

## Nueva arquitectura visual

### Gema Digital

Debe comunicar:

- IA productiva
- Ingeniería
- Software
- Automatización empresarial
- Innovación seria

Paleta dominante:

- Azul profundo `#0B192C`
- Cian IA `#00F2FE`
- Superficie clara `#F8FAFC`

### ERP Cumbre

Debe comunicar:

- Seguridad financiera
- Robustez
- Precisión contable
- Software transaccional de misión crítica

Paleta dominante:

- Azul slate `#0F172A`
- Verde esmeralda `#10B981`
- Oro moderado `#F59E0B`

## Taglines candidatos

Para Gema Digital:

1. IA · Software · Gestión Empresarial
2. Ingeniería de IA para Empresas
3. Software, IA y Automatización Empresarial
4. Infraestructura de IA y Gestión Empresarial

Para ERP Cumbre:

1. Software financiero de misión crítica
2. ERP en la nube para operación crítica
3. Gestión contable, fiscal y operativa en Google Cloud
